# Aithos Protect

Build a polished, highly visual MVP demo for a startup called AITHOS.

IMPORTANT:
This is a hackathon demonstration/prototype. Prioritize visual quality, smooth interactions, and a convincing end-to-end demonstration over complex backend infrastructure.

DO NOT build unnecessary authentication, database systems, payment systems, or complicated backend architecture.

The entire experience should work with realistic MOCK/SIMULATED data and interactions.

==================================================
PRODUCT
==================================================

Brand:
AITHOS

Tagline:
"INTELLIGENCE. PRIVATE. POWERFUL."

Core idea:
AITHOS is a privacy-preserving AI browser agent.

It allows AI to understand and perform tasks on webpages while protecting sensitive user information.

Core message:
"AI should know what it needs — not everything about you."

Demo principle:
SEE LOCALLY → PROTECT LOCALLY → REASON WITH SAFE CONTEXT → ACT SAFELY

==================================================
TECHNICAL SIMPLICITY
==================================================

Use mock data and local state.

Do NOT spend time creating:
- Real banking APIs
- Real user authentication
- Real financial systems
- Complex databases
- Payment systems
- Admin panels

The goal is a convincing functional prototype.

All PII is synthetic.

The "AI reasoning" can be simulated using predefined responses/state transitions.

The "privacy detection" can be simulated using predefined sensitive fields from the demo website.

The "browser action" can be simulated by triggering the button on the fake banking website.

However, structure the code cleanly so that real AI/model APIs and browser-extension functionality could be connected later.
